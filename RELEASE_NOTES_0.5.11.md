# Volleyball Manager Dev 0.5.11 — Windows x64

Versión de desarrollo para PC con Windows de 64 bits.

## Características destacadas
- Gestión de plantilla, fichajes, cantera y entrenamiento.
- Tácticas, rotaciones y decisiones durante los partidos.
- Partidos simulados punto a punto, con estadísticas y análisis.
- Calendario, competiciones y administración del club.
- Ambientación sonora y evolución continua del proyecto.

## Instalación
1. Descarga `Volleyball-Manager-Dev-0.5.11-Windows.zip` (159 MB).
2. Extrae el ZIP completo a una carpeta.
3. Ejecuta `Volleyball Manager Dev.exe` desde la carpeta descomprimida.

No hay instalador: esta edición es portable.
